# 链接全景

> 一眼看清当前文档的全部链接：出链、反链、提及、外部链接、资源引用与失效链接，点击即可跳转。

链接全景是一个思源停靠栏插件。写笔记时，一篇文档和整个笔记库的关系藏在不同角落里：块引用散在正文、反链藏在关系图、外部链接要翻源码。链接全景把这些全部收进右侧面板，当前文档「连着谁、被谁连着」，打开面板就能看到，点一下就能跳过去。

## 为什么用它

- **不用来回翻**：出链、反向链接、提及、外部链接、资源引用、失效链接，六类链接一个面板全列出，不用在文档、反链面板和源码之间切换。
- **每一条都能点**：块引用直接跳到目标块并高亮；外部链接用默认浏览器打开；资源在思源页签中打开。
- **看清引用方向**：出链显示「本文档 → 目标」，反链和提及显示「来源 → 本文档」，谁指向谁一目了然。
- **发现断链和孤岛**：目标已删除的引用会标为失效链接；没有任何链接的文档会标记为孤立文档，点击可列出整本笔记里的「孤岛」，适合整理笔记库。
- **顺手的整理工具**：搜索、按文档分组、排除日记、排除自引用、仅看当前笔记本，整理旧笔记时很好用。
- **字号可调**：界面字号 10–25px 可设，高分屏或宽侧栏下也能看得舒服。

### 适合你吗

适合你，如果：

- 你想了解一篇文档在笔记库中的位置和引用关系；
- 你在整理笔记库，需要找出失效链接和孤立文档；
- 你经常顺着引用跳转，希望有比反链面板更完整的视图。

可能不适合，如果：

- 你只需要看双向链接，思源自带的反链面板已经够用；
- 你想要可视化的关系图，这个插件是列表而不是图。

## 功能

- **出链**：当前文档指向其他块或文档的块引用。
- **反向链接**：其他块或文档指向当前文档的块引用。
- **提及**：其他文档正文中直接提到当前文档标题的位置（文档级）。
- **外部链接**：从文档 Markdown 中解析出的 `http(s)`、`mailto`、`tel` 链接。
- **资源引用**：图片、PDF 等 `assets/...` 资源引用。
- **失效链接**：目标块已被删除的引用。
- **方向标识**：出链显示「本文档 → 目标」，反向链接和提及显示「来源 → 本文档」。
- **搜索**：按标题、上下文、文档名或附加信息过滤。
- **分组**：按来源 / 目标文档分组，分组可折叠。
- **筛选**：排除日记、排除自引用、仅当前笔记本。
- **范围**：在「整篇文档」和「当前块」之间切换。
- **悬浮预览**：鼠标停在条目上时，在面板底部显示完整上下文；可关闭，也可手动点掉。
- **链接健康概览**：显示各类数量，并标记孤立文档；点击「孤立文档」可列出当前笔记本中没有出链、反向链接或提及的文档；点击分类统计可直接跳转并高亮对应区块。
- **键盘导航**：上下方向键移动，回车打开。
- **设置**：选择显示哪些区块、是否分组、自动刷新、最大条数、界面字号（10–25px）、悬停预览开关和默认筛选。
- **点击行为**：块引用打开目标块；外部链接用默认浏览器打开；资源在思源页签中打开。
- **右键菜单**：复制块引用、在新页签打开、左右/底部分屏打开、打开来源或目标文档。

## 使用

1. 启用插件。
2. 从右侧停靠栏打开「链接全景」。
3. 打开任意文档，面板会列出它的全部链接。
4. 点击条目跳转；鼠标悬停可查看完整上下文。

## 常见问题

**为什么「当前块」范围下看不到提及？**

提及是文档级的（其他文档正文提到当前文档标题），没有块级数据，所以只出现在「整篇文档」范围。

**「孤立文档」是什么意思？**

当前文档没有出链、反向链接，也没有任何文档提到它。点击这个标记会列出当前笔记本中所有这样的文档，方便你把「孤岛」笔记接入笔记库或归档。

**失效链接是怎么发现的？**

基于思源 `refs` 索引中目标块已不存在于 `blocks` 表的记录，和思源内核的判定一致。

**数据安全吗？**

插件只通过只读 API 读取索引和 Markdown，不写入任何笔记、块属性或工作区配置；也不会发起网络请求（外部链接只在你点击时才由系统打开）。

## 范围说明

- 提及为文档级，在「当前块」范围下不显示。
- 外部链接和资源引用从 Markdown 解析，不经过 `refs` 索引。
- 失效链接基于 `refs` 中 `def_block_id` 已不存在于 `blocks` 的记录。

## 数据影响

- 通过只读 API 读取 `refs`、`blocks`、反链索引和当前文档 Markdown。
- 不写入笔记、块属性或工作区配置。
- 不发起网络请求（只有点击外部链接时才会打开）。
