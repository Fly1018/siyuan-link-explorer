# 链接浏览器

一个思源停靠栏插件，列出当前文档的**出链**和**反向链接**，每一项都可以点击并跳转到对应块。

## 功能

- **出链**：当前文档指向其他块或文档的块引用。
- **反向链接**：其他块或文档指向当前文档的块引用。
- **提及**：其他文档正文中直接提到当前文档标题的位置（来自反链索引，文档级）。
- **外部链接**：从文档 Markdown 中解析出的 `http(s)`、`mailto`、`tel` 链接。
- **资源引用**：图片、PDF 等 `assets/...` 资源引用。
- **失效链接**：目标块已被删除的引用。
- **方向标识**：出链显示「本文档 → 目标」，反向链接和提及显示「来源 → 本文档」。
- **搜索**：按标题、上下文、文档名或附加信息过滤。
- **分组**：按来源 / 目标文档分组，分组可折叠。
- **筛选**：排除日记、排除自引用、仅当前笔记本。
- **范围**：在「整篇文档」和「当前块」之间切换。
- **悬浮预览**：鼠标停在条目上时，在面板底部显示完整上下文。
- **链接健康概览**：显示各类数量，并标记孤立文档；点击分类统计可直接跳转并高亮对应区块。
- **键盘导航**：上下方向键移动，回车打开。
- **设置**：选择显示哪些区块、是否分组、自动刷新、最大条数和默认筛选。
- **点击行为**：块引用打开目标块；外部链接用默认浏览器打开；资源在思源页签中打开。
- **右键菜单**：复制块引用、在新页签打开、左右/底部分屏打开、打开来源或目标文档。

## 使用

1. 启用插件。
2. 从右侧停靠栏打开「链接浏览器」。
3. 打开任意文档，面板会列出它的链接。
4. 点击条目跳转；鼠标悬停可查看完整上下文。

## 范围说明

- 提及为文档级，在「当前块」范围下不显示。
- 外部链接和资源引用从 Markdown 解析，不经过 `refs` 索引。
- 失效链接基于 `refs` 中 `def_block_id` 已不存在于 `blocks` 的记录。

## 数据影响

- 通过只读 API 读取 `refs`、`blocks`、反链索引和当前文档 Markdown。
- 不写入笔记、块属性或工作区配置。
- 不发起网络请求（只有点击外部链接时才会打开）。

## 开发
