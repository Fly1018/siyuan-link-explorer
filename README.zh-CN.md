# 链接速览 · Link Overview

![链接速览](preview.png)

把当前文档的出链、反向链接、提及、外部链接、资源引用和失效链接收进右侧停靠栏，点一下就能跳过去。不用在正文、反链面板和源码之间来回切换。

## 亮点

- **六类链接一处看全**：出链、反向链接、提及、外部链接、资源引用、失效链接。
- **点统计就切分类**：点「出链」只看这一类，再点一次恢复全部；其他分类同理。
- **资源按类型分组**：图片、视频、音频、PDF、文档、压缩包、其他。
- **发现缺失资源**：引用了但文件已不存在的资源会单独标记。
- **孤立文档在面板里看**：列出当前笔记本中没有出链、反链和提及的文档，点开就能处理。
- **库体检**：一眼看到整个笔记本的死链、缺失资源和链接最多的文档。
- **链接报告**：一键把当前列表复制为 Markdown，方便整理或反馈。
- **每条都能点**：块引用跳到目标块并高亮，外部链接用默认浏览器打开，资源在思源页签中打开。
- **方向一眼可见**：出链显示「本文档 → 目标」，反链和提及显示「来源 → 本文档」。

## 使用

1. 在「集市 → 已下载 → 插件」中启用「链接速览」。
2. 打开任意文档，点击右侧停靠栏的链接图标。
3. 面板列出当前文档的六类链接，点击条目即可跳转。

### 只看某一类

点击顶部的统计按钮（例如「3 出链」），面板会切换成只显示这一类；再次点击同一个按钮恢复全部。

切换文档，或在「整篇文档 / 当前块」之间切换时，会自动恢复为显示全部。

### 检查孤立文档

当前文档没有出链、反向链接，也没有被其他文档提及时，面板会出现「孤立文档」标记。点击后，面板原地切换为孤立文档列表：

- 列出当前笔记本中没有出链、反向链接和提及的文档；
- 点击文档直接打开，列表会保留，方便连续处理；
- 点「返回链接」回到当前文档的链接视图。

为保证响应速度，扫描范围是当前笔记本中最近更新的 80 篇文档。

### 库体检

点击面板里的「库体检」，可以查看当前笔记本的整体链接状况：

- 文档数、失效链接数、缺失资源数；
- 缺失资源清单（文件路径）；
- 死链最多的文档、链接最多的文档、被引用最多的文档，点击可直接打开。

点「返回链接」回到当前文档。

### 复制报告

点击面板右上角的复制按钮，会把当前显示的内容（当前分类、搜索和筛选结果）复制为 Markdown 列表，包含标题、上下文、类型和资源缺失标记。可以直接贴进文档做整理清单。

### 资源引用

资源引用从文档 Markdown 中解析，并按文件类型分组：

| 类型 | 常见扩展名 |
| --- | --- |
| 图片 | png、jpg、jpeg、gif、webp、svg、avif、heic 等 |
| 视频 | mp4、webm、mov、mkv、avi 等 |
| 音频 | mp3、wav、flac、m4a、aac 等 |
| PDF | pdf |
| 文档 | doc/docx、xls/xlsx、ppt/pptx、csv、md、epub 等 |
| 压缩包 | zip、rar、7z、tar、gz 等 |
| 其他 | `assets/` 下其余类型的文件 |

思源把视频和音频导出为 `<video>`、`<audio>` 标签，插件同样会识别并按类型归类。

引用了但文件已经不存在的资源会显示「文件缺失」标记，资源分区顶部和「库体检」里也会给出数量。

## 界面说明

- **顶部**：当前文档标题、复制报告、设置、刷新。
- **范围**：在「整篇文档」和「当前块」之间切换。
- **统计**：六类链接的数量，点击可只看该类，再点恢复全部；旁边还有「孤立文档」和「库体检」入口。
- **搜索**：按标题、上下文、文档名或附加信息过滤。
- **筛选**：排除日记、排除自引用、仅当前笔记本、全部展开/折叠。
- **列表**：按文档分组（资源按类型分组），分组可折叠；条目显示方向、上下文、类型和重复引用次数。
- **悬浮预览**：鼠标停在条目上，面板底部显示完整上下文；可点击关闭，滚动时自动收起。
- **键盘**：`Esc` 清空搜索与筛选，`/` 聚焦搜索，`Home`/`End` 跳到首尾；上下方向键移动，回车打开。

## 设置

| 设置 | 说明 |
| --- | --- |
| 显示内容 | 选择显示哪些区块：提及、外部链接、资源引用、失效链接 |
| 隐藏空分区 | 没有内容的分类不再占位 |
| 按文档分组 | 链接按来源/目标文档分组；资源始终按文件类型分组 |
| 编辑后自动刷新 | 文档内容变化后自动更新列表 |
| 单类最多显示 | 每类最多显示 50–2000 条，默认 500 |
| 界面字号 | 10–25 px，默认 13 px |
| 悬停显示预览 | 关闭后不再弹出悬浮预览 |
| 排序方式 | 默认、按标题、按最近更新 |
| 默认筛选 | 排除日记、排除自引用、仅当前笔记本的默认状态 |

设置保存在插件私有存储中，更新插件不会丢失。

## 常见问题

**「提及」是什么？**

其他文档正文中出现当前文档标题的位置。提及是文档级的，所以在「当前块」范围下不显示。

**为什么只有失效链接的文档也会标为孤立文档？**

失效链接的目标块已经不存在，不算有效出链。孤立文档列表使用同一口径，因此这类文档也会出现在列表里。

**外部链接会联网吗？**

不会。插件不发起任何网络请求，只有你点击外部链接时，才交给系统浏览器打开。

**点击资源会怎样？**

图片、PDF、视频等资源在思源的页签中打开，不会调用系统看图或播放器。

**「文件缺失」是什么意思？**

资源引用的路径在 `assets/` 下找不到对应文件，常见于手动删除、同步冲突或从别处复制文档。插件只做标记，不会修改或删除引用。

**数据安全吗？**

插件只通过只读 API 读取索引和 Markdown，不改动笔记内容、块属性或工作区配置。会写入的只有面板设置（`data/storage/petal/siyuan-link-explorer/`）。

**支持移动端吗？**

目前只支持桌面端、桌面窗口和网页版桌面布局，移动端不可用。

**发布模式或只读模式下能用吗？**

只读浏览可以正常使用；发布模式下插件私有存储可能无法写入，此时设置不会保存。

## 兼容性

- 思源笔记 3.8.0 及以上。
- 桌面端、桌面窗口、网页版桌面布局。
- 使用思源主题变量和深色主题，不覆盖全局 `b3-*` 样式。

## 安装与更新

在「集市」搜索「链接速览」安装；更新时通过「集市 → 已下载 → 插件」升级，已有设置会保留。
